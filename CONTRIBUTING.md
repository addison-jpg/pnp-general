# Contributing

Corrections are the most useful contribution.

- **Found a mistake, or a claim stronger than its evidence?** Open an issue. Name the file and line, the claim, and what you think is wrong. Every result here carries a label (checked, checked-finite, tested, open, refuted); a mislabel is a bug.
- **Want to check a result yourself?** Each finding names a runner. For example: `python3 -I biology/privacy/check.py`, `python3 -I biology/brain/neuron/check.py`, `python3 -I philosophy/milnor.py`. Lean results build with `lake build` in the project that holds them.
- **Pull requests** are welcome for fixes to proofs, checks, citations and documentation. Please keep claims at the strength the evidence supports.
