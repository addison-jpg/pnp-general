# philosophy/

A crude, checked formal model of one reading of Deleuze's core concepts (multiplicity,
difference, virtual / actual, problem / solution, intensity), built up a ladder of existing
formalisations: mereology, Spinoza, Leibniz, then Deleuze.

It models cited readings (DeLanda, Duffy, Smith, Plotnitsky, Lautman). It claims nothing about what
Deleuze meant, and a model is not a proof about a text.

- [`PLAN.md`](PLAN.md): the ladder, the first Lean definitions, the bridge to this repository.
- Lean code (later seats): `lean/PEqualNP/Philosophy/`, importing only Mathlib.
- Literature with honest read status: `LITERATURE.md`, section M. Board: `boards/tasks/philosophy-formal.md`.
