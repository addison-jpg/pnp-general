# Language data

`glottolog_languoid.csv` and `glottolog_README.txt`: the Glottolog languoid table (Hammarstrom, Forkel, Haspelmath, Bank and colleagues; Glottolog is licensed CC BY 4.0). Downloaded from Zenodo, record 24104033. Attribution: Glottolog, glottolog.org.

`languages.csv`: written by `culture/language/glottolog_forest.py` from the table above (families and languages, not dialects). It is checked by `culture/language/forest.py`.
