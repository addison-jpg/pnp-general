Board structure
- boards/tree.json: a dict of 71 directories. Each holds "counts" (word -> number of verified findings in the subtree),
  "verified" (list of finding ids) and "unverified_here" (list of {id, why}). Root ".": 141 verified ids,
  counts checked 91, checked-finite 32, tested 12, refuted 6. 121 unverified entries across all directories.
- boards/TREE.md: the same tree as text, generated by `python3 -I boards.py`, not to be edited by hand.

Node fields (one finding in a findings.jsonl; 262 distinct ids today)
- id, time, who, serves, word, statement, evidence (list of "path" or "path::name"), by (list)   all 262 have these
- runner (80 have it), retest (2 have it), reduction (0 have it; needed only for checked-infinite)
Brief's field names mapped: id = id; label = word; program = serves (the bracket tag in TREE.md); claim = statement;
evidence = evidence; seat = who (writer) plus by (second seats).

Label set
- The brief's six labels: checked, checked-finite, tested, refuted, analogy, open.
- boards.py WORDS (eight): checked, checked-finite, checked-infinite, paper, tested, refuted, open, premise.
- "analogy" is NOT a board word: boards.py marks a finding with word "analogy" unverified ("word"), and an asteroid
  `record` with word analogy is skipped. "analogy" is used as a label only in prose (workshop/ath_prompts/ATTACK.md).
- Words in use today: checked 100, checked-finite 58, tested 51, open 35, refuted 13, paper 5.

Seat rule (boards.py verified())
- Every finding has a "who": true for all 262.
- A non-`checked` finding needs a name in "by" other than "who" (a second seat). 210 of 262 have no second seat.
