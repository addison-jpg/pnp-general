# Induction route for L-meta-951 (paper only)

Convention: instances allow singleton sets (contribute 0, may be dropped). Minimal counterexample (MC): smallest n+m+s with s<base. Restricting a variable to a constant gives a valid instance (h' monotone; if h' is constant, N is deleted and the monotone bound applies).

## Proved
L1 (hardness under restriction). x_w:=1: surviving sets (w not in S) keep their status (point z_S already has x_w=1); sets through w become constant. x_w:=0: sets through w keep status (new complement point = old z_S restricted); sets not through w go from h(z_S) to h(z_{S+w}) <= h(z_S): easy stays easy, hard may become easy. So hard-set count never increases under x_w:=0.
L2 (every variable has a non-N reader). If x_w (w in S) were read only by N, o_S would be antitone in x_w (N=not h, h monotone), but o_S is monotone and depends on x_w. Contradiction. So fixing x_w:=0 kills a gate g != N reading it (OR(0,y)->y, AND(0,y)->0): k>=1; k>=2 if h=x_w (N also dies).
L3 (counting). If x_w:=0 kills k gates and w lies in d sets, base drops by d, size by >=k. Minimality gives s >= s'+k >= base-d+k. So a MC has k <= d-1 for every w. Consequences, all rigorous: (i) variables in no set can be fixed (base unchanged, s'<=s), so [n]=union of S_i; (ii) every variable lies in >=2 sets; (iii) a variable of degree 2 has exactly one reader, and h != x_w; generally #readers(w) (counting N if h=x_w) <= d(w)-1.
Sanity: in the monotone case fan-out < degree is possible only via sharing like g=x_v OR (x_a AND x_b) with a in S1, b in S2, which costs an extra AND, so local counting alone cannot finish (the monotone Boolean-sum bound itself needs the merge argument of Theorem X, not plain variable elimination).
L4 (two hard sets, exact condition). Theorem X applies to a hard pair (S,S') iff some transversal T of the minterms of h with T ⊇ S' (or S) meets the other set in <=1 point. E.g. h=x1x2 v x3x4, S={1,2}, S'={3,4}: T_S'={3,4,1} works. It fails only if both S and S' contain, outside the other, minterms-to-hit needing >=2 points of the other set, i.e. minterms of h disjoint from S' whose hitting set inside S\S' must have size >=2 (plus S∩S' effects), and symmetrically.

## Not proved (exact obstruction)
(1) Induction on hard sets would need: for a MC with >=2 hard sets and h(1_X)=1, a variable w with kills(w) >= d(w). L1 shows hardness is well behaved under restriction, but L3 shows the killed-gate count is the bottleneck, and fan-out < degree is not contradicted by anything local. Restricting x_w:=1 for w in a hard S kills every set through w (base drop sum (|S'|-1)); the killed gates are only the exclusive cones of those outputs, and nothing forces them to be that large without the merge argument.
(2) So the reduction "MC has <=1 hard set or h(1_X)=0" is NOT obtained. What remains is exactly the hard-hard pair obstruction of Theorem X (two hard sets that each force a transversal to hit the other in >=2 points, so one OR gate can be charged by both). Needed: a C0/C1 hybrid charging with atoms P_u=e_u+Q_u (h(P_u)=1) in C0: then B(g) ⊆ {u: u in T or Q_u meets T}, which changes the collision condition to Q-sets; I did not verify this closes the gap (guess).
